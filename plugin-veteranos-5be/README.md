# Plugin Oficial: Veteranos 5º BE Cmb Bld
### Batalhão Juarez Távora — Porto União - SC / União da Vitória - PR

O **Plugin dos Veteranos do 5º BE** integra toda a inteligência tática, regras cerimoniais militares, dados do efetivo histórico de 658 militares e automações para o Grande Reencontro e Almoço de Confraternização.

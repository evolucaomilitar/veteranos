# 🌐 Guia Oficial: Como Publicar o Sistema no Vercel (Gratuito)
### Sistema dos Veteranos 5º BE Cmb Bld — Batalhão Juarez Távora

Este guia explica o passo a passo para colocar o sistema no ar na internet com link seguro HTTPS (exemplo: `https://veteranos-5be.vercel.app`) para que todos os 658 veteranos possam acessar no celular pelo WhatsApp e instalar como aplicativo PWA.

---

## 🚀 Método Mais Fácil: Arrastar e Soltar no Navegador (2 Minutos)

1. **Acessar o Vercel**:
   - Entre no site oficial: [https://vercel.com](https://vercel.com)
   - Clique em **Sign Up** (Cadastro gratuito) e entre com sua conta do Google, GitHub ou Email.

2. **Fazer o Deploy da Pasta**:
   - No painel do Vercel, clique no botão azul **Add New...** ➔ **Project**.
   - Se estiver usando o [Vercel CLI](https://vercel.com/cli) no computador:
     - Abra o terminal na pasta do projeto e digite apenas `vercel`.
   - Ou simplesmente envie o repositório para o seu GitHub e selecione o repositório na tela do Vercel.

3. **Configuração Automática**:
   - O Vercel lerá automaticamente o arquivo [`vercel.json`](file:///C:/Users/Usuario/.gemini/antigravity/scratch/veteranos_5be/vercel.json) já configurado.
   - Clique em **Deploy**.
   - Em menos de 1 minuto, seu site estará publicado com link mundial e certificado SSL/HTTPS gratuito!

## 📱 Como os Veteranos Instalam no Celular (PWA)

- **No Android (Chrome)**:
  - Ao abrir o link, o site exibe o botão dourado **[ 📲 Instalar App do 5º BE ]**.
  - O ícone do Batalhão Juarez Távora é adicionado diretamente na tela de aplicativos do celular.
  - Funciona mesmo sem internet ou com sinal fraco!

- **No iPhone / iPad (Safari)**:
  - O veterano toca no botão de **Compartilhar** do Safari (quadrado com seta para cima) e seleciona **"Adicionar à Tela de Início"**.
